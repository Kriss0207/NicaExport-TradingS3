# NicaExport Trading, S.A.

## Análisis de Operaciones de Comercio Internacional

Proyecto académico realizado para la asignatura Tecnologías de Gestión de Información de la carrera de Negocios Internacionales.

### Descripción

Este repositorio contiene el trabajo realizado para el análisis de las operaciones internacionales de NicaExport Trading, S.A.

El proyecto incluye el análisis y organización de información relacionada con las operaciones de comercio internacional mediante el uso de Excel, PowerPoint y GitHub.

### Contenido del repositorio

Excel

Archivo utilizado para el análisis de las operaciones internacionales, incluyendo las funciones, tablas dinámicas, gráficos y resultados obtenidos.

PowerPoint

Presentación elaborada a partir de los resultados obtenidos en el análisis de las operaciones internacionales.

### Análisis realizado

En el proyecto se analizaron aspectos relacionados con el Valor FOB, utilidad, margen, países de destino, productos, regiones y operaciones pendientes.

También se utilizaron funciones de Excel, tablas dinámicas y gráficos para facilitar el análisis y la interpretación de los resultados.
